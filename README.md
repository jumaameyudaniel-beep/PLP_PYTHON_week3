# Grade Reporter & Bug Hunt

This assignment practices Python loops, conditionals, running totals, and debugging.

## Files

* `grade_reporter.py` - Uses a for loop and if/elif/else conditions to assign grades, count passes and failures, and calculate the average.
* `bug_hunt.py` - Finds and fixes three bugs in a while loop program that calculates the sum from 1 to 5.

## Bug Hunt Reflection

The hardest bug to find was the loop condition because it did not produce an error message. The program could run, but it stopped before adding 5, so it printed the wrong answer. I knew something was wrong because the expected sum of 1 to 5 is 15, but the program produced 10.
